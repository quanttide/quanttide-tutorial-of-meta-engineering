# 形而上学、本体论与范畴论

元工程干的活，说到底是把一段模糊的需求变成可以检查的东西。这件事要有个起点，先得回答一个更早的问题：这段需求里，到底有哪些东西是存在的。

这一章的三篇，回答三个依次收窄的问题。

- [形而上学](./metaphysics.md)：存在与实在这个问题在问什么，它和本体论、范畴论是什么关系。
- [本体论](./ontology.md)：系统里有哪些东西，这份清单怎么列。
- [范畴论](./ontologic_category.md)：这些东西按存在方式分成哪几类。

三篇给出的是一张概念清单，不是方法。怎么把一段真实的需求钉到这张清单上、怎么写成数学、怎么落到代码，在下一章：[形而上学入门](../../metaphysics/intro/index.md)。
