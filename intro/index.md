# 概念入口

元工程的方法现在走四个阶段：需求、意图、规格、实现。需求把话说明白，意图把话说严谨，规格把严谨的话变成机器能查的表达，实现把表达落进具体的编程语言。四者次序固定，前一阶段的产物是后一阶段的输入，验收不过就退回上一阶段。

这个目录是概念入口，两篇正文各管一件事：[四个阶段](./layer.md)把这套主题本身讲透；[用形而上学识别问题](./metaphysics.md)讲拿到一个说不清的需求时，怎么先把问题本身的结构看出来。

## 本目录

- [四个阶段](./layer.md)：需求、意图、规格、实现各自在做什么、按什么顺序走、怎么算过——先读这篇。
- [用形而上学识别问题，让设计从结构里长出来](./metaphysics.md)：悬置现象、范畴发明、关系建模、边界测试、元层反思、设计推导六步。
