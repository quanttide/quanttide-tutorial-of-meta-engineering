# quanttide-tutorial-of-meta-engineering

量潮元工程教程——从哲学分支进入形式化建模的入门教程。

## 概述

本仓收录元工程的方法教程，目前分两处。`intro/` 是概念入口，从学科分类讲到形而上学、本体论、范畴论；`metaphysics/intro/` 是方法正课，六篇走同一套动作——业务需求、哲学阐述、数学表达、代码实现。

本版只覆盖五大分支里的形而上学一支，其余分支与站点部署待后续版本。维护状态见 [`STATUS.md`](STATUS.md)，写法见 [`CONTRIBUTING.md`](CONTRIBUTING.md)，给 AI 的说明见 [`AGENTS.md`](AGENTS.md)。
