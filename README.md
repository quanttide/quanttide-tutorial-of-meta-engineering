# quanttide-tutorial-of-philosophy

量潮哲学教程——按哲学分支组织的入门教程。

## 概述

本仓收录按哲学分支组织的入门教程。学科分类是入口；形而上学、本体论、范畴论一组；形式化建模的本体基元与状态机前后置条件一组。另有章程式工作与标准化两篇。
