# quanttide-tutorial-of-meta-engineering

量潮元工程教程——从哲学分支进入形式化建模的入门教程。

## 概述

本仓收录元工程的方法教程，目前分两处。`intro/` 收一篇用形而上学识别问题的方法文章；`metaphysics/intro/` 只剩入口指针——《四个阶段》与六篇形式化正课已随领域边界重划迁至软件工程教程仓（quanttide-tutorial-of-software-engineering，`intro/layer.md` 与 `formalization/`）。形而上学、本体论、范畴论三篇概念稿已移入图书馆仓作参考资料。

本版只覆盖五大分支里的形而上学一支，其余分支与站点部署待后续版本。维护状态见 [`STATUS.md`](STATUS.md)，写法见 [`CONTRIBUTING.md`](CONTRIBUTING.md)，给 AI 的说明见 [`AGENTS.md`](AGENTS.md)。
